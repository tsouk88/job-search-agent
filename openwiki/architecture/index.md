# Files

- [Agent Graph](agent-graph.md) - The LangGraph state machine in agent.py — fan-out to five job API fetchers via the Send API, collect_results with company+title deduplication, location and age filtering, and title-weighted scoring with alias normalization and frequency-based description scoring.
- [Backend API](backend-api.md) - The FastAPI backend in main.py — lifespan compiling two graphs (PostgresSaver agent + InMemorySaver eval_agent), ten endpoints, Redis-backed rate limiting, Gemini budget, and per-query job cache, Celery async upload with job polling, keycheck header auth, n8n digest dedup, the country-aware searchhelper cache, and markdown response formatting.
- [Architecture Overview](overview.md) - Three interfaces (REST, MCP, Voice) over one deterministic LangGraph agent graph. The search path is LLM-free. The LLM boundary covers feedback extraction, async CV parsing, and the auth-gated evaluator, plus an eval-only graph entrypoint. Postgres, Redis, and Celery back REST; MCP and Voice use lighter persistence.
